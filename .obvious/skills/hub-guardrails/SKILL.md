# Hub guardrails

## Data contract
- `src/data/rooms.json` is generated by `scripts/gen-rooms.mjs` from Notion plus the hand-owned overlay `src/data/rooms.curated.json`, and parsed by zod in `src/lib/rooms.ts` at import. A malformed file fails the build.
- **Never hand-edit `rooms.json`.** Overlay fields are documented at the top of `src/lib/rooms.ts`.
- New public data follows the same pattern: a committed JSON file, a zod schema in `src/lib/`, parsed at import, and scanned by `verify-public-safe.mjs`, which covers `src/data/**`.

## Guarded files (agents: never edit)
`scripts/verify-public-safe.mjs` · `scripts/gen-rooms.mjs` (it reads Notion; changes need human review) · `.env*` · `.github/workflows/public-safety.yml`.

## Design system
House tokens in `src/app/globals.css`: dark base, signature acid green `#8FE83A` (underline and name mark), topic accents. Reuse the existing components in `src/components/`; don't add a UI library.

## Verify
`pnpm check` (public-safe scan, system-map verify, rooms tests) · `pnpm lint` · `pnpm build`.
