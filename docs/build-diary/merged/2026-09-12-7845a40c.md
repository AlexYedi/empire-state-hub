## 2026-09-12 — Sessions, not branches

Three Claude sessions sharing one working checkout was caught from the inside: a reconciliation pass stashed a sibling session's uncommitted work, watched a branch tip move three times between two commands, and found the main checkout sitting on another session's feature branch. The code had self-merged unprompted — the failure was never branches refusing to merge but sessions colliding on one checkout, and that diagnosis is what made the reconciliation rules necessary.
